## Architecture Lessons for Our Portfolio Roadmap

| Component / Phase | What Common Portfolios Do | What Awwwards & Flagship Sites Do |
| :--- | :--- | :--- |
| **Canvas Lifecycle** | Mount 5+ separate `<Canvas>` tags | Mount **one persistent background canvas**; use scissor test or renderTarget to project scenes. |
| **Animation Engine** | Trigger uncoordinated CSS keyframes | Coordinate with **GSAP Timeline** or **Framer Motion spring** linked directly to scroll deltas. |
| **Performance** | Run requestAnimationFrame constantly | Use `useInViewport` or `demand` mode: **stop rendering when static or offscreen**. |
| **Asset Delivery** | Load uncompressed 40MB GLTFs | Use **Draco compression**, `.glb` mesh quantization, and pre-rendered WebP canvas sequences. |
| **Mobile UX** | Force heavy desktop 3D scenes | Fallback to hardware-accelerated CSS transforms or low-LOD wireframes under 768px. |
